# ipcgen

Android app project scaffold for IPCGen, a QEMU-driven virtual machine launcher.

This repository contains a starter Android project intended for AIDE import, with the package name `com.iBlast.ipcgen` and version `1.0`.

It includes:
- A launcher UI to choose an ISO/IMG image
- QEMU command preparation logic
- Background service support
- Android 6 / API 23 compatibility settings
- Network, audio, and system permission declarations
